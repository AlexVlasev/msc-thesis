\chapter{Group of Order 8}
%========================

\section{Preparation}
There are 2 non-isomorphic cases of random walk models on the plane that have group of order 8. They have step polynomials
\begin{align}
S &= \ol{x}_1+x_1+\ol{x}_1x_2+x_1\ol{x}_2\\
S &= \ol{x}_1+x_1+\ol{x}_1\ol{x}_2+x_1x_2
\end{align}
We'll work on the first one since it has already been covered in the two-friendly-walks paper and this will provide us with an opportunity to compare. Here
\begin{align}
	S_1^{-1} &= 1+x_2,\quad S_1^0 = 0,\quad S_1^1 = 1+\ol{x}_2\\
	S_2^{-1} &= x_1,\quad S_2^0 = x_1+\ol{x}_1,\quad S_2^1 = \ol{x}_1
\end{align}
which give
\begin{align}
	A = K_1 = c_1 - t\ol{x}_1(1+x_2)\quad\quad B = K_2 = c_2 - t x_1\ol{x}_2
\end{align}
Note that since $\Sf{-1,-1} = 0$
\begin{align}
	K_{12} = c_1c_2
\end{align}
and we can combine the $\alpha$ term with $K_{1,2}Q_{1,2}^{0,0}$ in one
\begin{align}
	\gamma = \ol{a}_1\ol{a}_2(1-b_1b_2\Qf{0,0})
\end{align}
and the master functional equation is
\begin{align}
-KQ + K_1 Q_1^0 + K_2 Q_2^0 +\gamma = 0
\end{align}
The roots of the kernel are
\begin{align}
	\sigma_1^\pm &= \frac{1\pm\sqrt{1-4t^2(1+x_2)(1+\ol{x}_2)}}{2t(1+\ol{x}_2)}\\
	\sigma_2^\pm &= \frac{1-t(x_1+\ol{x}_1) \pm \sqrt{(1-t(x_1+\ol{x}_1))^2 - 4t^2}}{2t\ol{x}_1}
\end{align}
and as in the paper we pick $\sigma_k = \sigma_k^{-}$ because they are power series in $t$. Next we determine the birational transformations that leave the kernel unchanged. They are
\begin{align}
	g_1: x_1 \mapsto \ol{x}_1x_2\quad\quad g_2: x_2 \mapsto x_1^2 \ol{x}_2
\end{align}
Simply iterating $g_1$ and $g_2$  shows that the group $G$ has order 8. For the rest of the analysis we'll need the following notation.
\begin{definition} For a concatenated list $L = L_1L_2\ldots L_n$of integer indices let $g_L = g_{L_1}\ldots g_{L_n}$ and for some term $X$ (for example $A$ or $B$) we let $X_L = g_L(X)$.
\end{definition}
The elements in the orbit are $id, g_1,g_{21},g_{121}$, etc. Since eventually we reach the identity again we can work backwards and have the $g$ terms meet in the middle. The orbit is then given by
\begin{align}
	Orbit(G) = \{id, g_1, g_{21},g_{121},g_{2121}=g_{1212}, g_{212},g_{12},g_{2}\}
\end{align}
In the rest of this calculation we need to eliminate the kernel term via a substitution of $\sigma_k$ in the master equation (We'll overload the notation as before). Then we'll need some extra functional equations that are obtained by application of terms from the orbit. However not all such applications are valid. We require that the $\sigma_k$ term appears in the numerator inside the functions $Q$. We can check that to use the sigma values we need to use the following transformations
\begin{align}
	\sigma_1: id, g_2, g_{21}, g_{212}\\
	\sigma_2: id, g_1, g_{12}, g_{121}
\end{align}
For each $\sigma_k$ we're going to obtain 3 additional functional equations to complement the master equation and then we'll substitute $x_k = \sigma_k$ into the results to eliminate the kernel term. Because of this we just won't include the kernel term from the start. The variable elimination method involving the different equations will work with or without the substitution $x_k = \sigma_k$. We'll also ignore the $\gamma$ term for now and just work with the $Q_1^0$ and $Q_2^0$ terms. On this note we'll also drop the 0s from the exponents and write $Q_k^0 = Q_k$. The method is essentially linear algebra but because of the complexity and symmetry involved in the coefficients it's best to investigate the explicit simplification of the equations.

\section{The $\sigma_1$ substitution}
%========================
A simple but tedious check shows that there are no non-trivial relations for $A$, $B$ and application of elements from the $\sigma_1$ orbit besides $A_{212} = A$.
\begin{align}
	g_{21}Q_1 = g_2 Q_1,\quad g_2 Q_2 &= Q_2,\quad g_{212} Q_2= g_{21} Q_2
\end{align}
The functional equations have the terms
\begin{align}
	id:&\quad AQ_1+BQ_2 \\
	g_2:&\quad A_2 g_2Q_1 + B_2 Q_2\\
	g_{21}:&\quad A_{21}g_2Q_1 + B_{21}g_{21}Q_2 \\
	g_{212}:&\quad A_{212} g_{212}Q_1 + B_{212} g_{21}Q_2
\end{align}
To eliminate variables we'll take do the following transformations of the equations
\begin{align}
	(1) &= B_2 id - B g_2 \Longrightarrow AB_2 Q_1 - A_2 B g_2 Q_1\\
	(2) &= B_{212} g_{21} - B_{21} g_{212} \Longrightarrow A_{21}B_{212} g_2 Q_1 - A_{212} B_{21} g_{212} Q_1
\end{align}
and finally we'll take
\begin{align}
	(3) &= A_{21}B_{212}(1) + A_2 B (2)\\
	&\Longrightarrow A_{21}B_{212}A B_2 Q_1 - A_2 B A_{212} B_{21} g_{212} Q_1
\end{align}
The resulting expression can be written more compactly as
\begin{align}
(1-g_{212})(A_{21}B_{212}A B_2 Q_1)  = A (1-g_{212})(A_{21}B_{212} B_2 Q_1)
\end{align}
We obtain the expression for the coefficient of $\gamma$ by following the transformations. We obtain the following term
\begin{align}
	[A_{21}B_{212}(B_2 - B)+A_2 B(B_{212} - B_{21})]\gamma
\end{align}

\section{The $\sigma_2$ substitution}
%========================
A simple but tedious check shows that there are no non-trivial relations for $A$, $B$ and application of elements from the $\sigma_2$ orbit besides $B_{121} = B$. The relations between the $Q$'s are
\begin{align}
	g_{1}Q_1 =  Q_1,\quad g_{121} Q_1= g_{12} Q_1, g_{12} Q_2 &= g_1Q_2
\end{align}
The functional equations have the terms
\begin{align}
	id:&\quad AQ_1+BQ_2 \\
	g_1:&\quad A_1 Q_1 + B_1 g_1 Q_2\\
	g_{12}:&\quad A_{12}g_{12}Q_1 + B_{12}g_{1}Q_2 \\
	g_{121}:&\quad A_{121} g_{12}Q_1 + B_{121} g_{121}Q_2
\end{align}
To eliminate variables we'll take do the following transformations of the equations
\begin{align}
	(1) &= A_1 id - A g_1 \Longrightarrow A_1B Q_2 - A B_1 g_1 Q_2\\
	(2) &= A_{121} g_{12} - A_{12} g_{121} \Longrightarrow A_{121}B_{12} g_1 Q_2 - A_{12} B_{121} g_{121} Q_2
\end{align}
and finally we'll take
\begin{align}
	(3) &= A_{121}B_{12}(1) + A B_1 (2)\\
	&\Longrightarrow A_{121}B_{12}A_1 B Q_2 - A B_1 A_{12} B_{121} g_{121} Q_2
\end{align}
The resulting expression may be written more compactly as
\begin{align}
	(1-g_{121})(A_{121}B_{12}A_1 B Q_2) = B(1-g_{121})(A_1A_{121}B_{12}Q_2)
\end{align}
We obtain the expression for the coefficient of $\gamma$ by following the transformations to
\begin{align}
	[A_{121}B_{12}(A_1 - A)+A B_1(A_{121} - A_{12})]\gamma
\end{align}

\section{Partial Orbital Operators}
%========================
We may think of the elimination of $Q$'s with undesirable arguments as a transformation of the original functional equation. We take two functional equations and produce one with a function eliminated. Then we take both of these to produce the final equation. Each of these steps may be done with such an operator. For example the first transformation becomes
\begin{align}
	B_2 id - B g_2 = (1-g_2)B_2
\end{align}
that acts in the following way
\begin{align}
	 ((1-g_2)B_2)(f) = g_2(B)f - B g_2(f)
\end{align}
This inspires the following notation.
\begin{definition} Let $L$ be a concatenated list and $X$ be some function. We define the following operator via its action on any function $F$
\begin{align}
	D_L(X)(F) = g_L(X) F - X g_L(F)
\end{align}
\end{definition}
The notation is reminiscent of a derivative, specifically in the numerator of the quotient rule. So the first transformation can be written as
\begin{align}
	B_2 id - B g_2 = D_2(B)
\end{align}
The second transformation is a little more involved
\begin{align}
	& B_{212} g_{21} - B_{21} g_{212}\\
	=& g_{212}(B g_{2} - B_{2})\\
	=& -g_{212}D_2(B)
\end{align}
The final transformation is
\begin{align}
	D^{(1)} &= A_{21}B_{212} D_2(B) - A_2 B g_{212} D_2(B)\\
	&= (1-g_{212})(A_2 B)D_2(B)\\
	&= D_{212}(A_2B) D_2(B)
\end{align}
This operator is reminiscent of the Orbital operators that we've seen previously. It eliminates the $Q_2$ term with the undesirable argument and replaces it with a more desirable one. We can re-write the result in the following manner
\begin{align}
 A (1-g_{212})(A_{21}B_{212} B_2 Q_1)= A D_{212}( A_2 B B_{21}) (Q_1)
\end{align}
This leads to the following theorem
\begin{theorem} For the $\sigma_1$ substitution we have
\begin{align}
	0 = D^{(1)}(A Q_1 + B Q_2 + \gamma) = A D_{212}( A_2 B B_{21}) (Q_1)  +\gamma D_{212}(A_2B)(B_2 - B)
\end{align}
Similarly for the $\sigma_2$ substitution we have
\begin{align}
	0 = D^{(2)}(A Q_1 + B Q_2 + \gamma) = B D_{121}( A A_{12} B_1) (Q_2)  +\gamma D_{121}(A B_1)(A_1 - A)
\end{align}
\end{theorem}
The resulting equations are actually better written out as
\begin{align}
	\sigma_1: \quad D_{212}( A_2 B B_{21}) (Q_1)  +\gamma \frac{D_{212}(A_2B)(B_2 - B)}{A} &= 0\\
	\sigma_2: \quad D_{121}( A A_{12} B_1) (Q_2)  +\gamma \frac{D_{121}(A B_1)(A_1 - A)}{B} &=0
\end{align}
The interesting fact (as calculated in the paper) is that the coefficients in front of the $Q$'s become Laurent polynomials once we take into consideration the $\sigma_k$ substitutions, even though $\sigma_k$ contains a square root. The coefficients in front of $\gamma$ can be reduced to a rational function plus a rational function times a square root after properly conjugating. The calculations are exceedingly complicated and unlikely to be done easily by hand. The square root part does not depend on $a_2$ in the first case and $a_1$ in the second case.
