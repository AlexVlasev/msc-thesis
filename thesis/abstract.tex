\chapter{Abstract}

In this work we apply an operator approach to multidimensional random walk enumeration in order to automatize some of the process in solving these problems. In particular given a random walk model in any number of dimensions we can use operators to write down a functional equation $(1-t\Gamma S)Q = q$ for the generating function $Q$ where $\Gamma$ is an operator and $S$ is the Laurent step polynomial for the model. Further we use the operator perspective to further and unify some of the different kernel methods (orbit and obstinate methods in particular). This operator paradigm work for both classic random walk models and models with interactions with hyperplanes. Near the end we solve some two-dimensional problems with interactions.
