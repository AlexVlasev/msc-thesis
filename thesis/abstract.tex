\chapter{Abstract}

In this work we explore the the application of operators to enumeration of multidimensional random walks with a focus on walks which interact with the boundary hyperplanes. Using operators makes the derivation of the functional equations a lot easier and some preliminary work shows that using operators is the way to go when solving problems of this nature.
