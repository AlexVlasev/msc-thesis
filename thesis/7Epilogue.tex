\chapter{Epilogue}
\label{ch:Epilogue}
%================================

In this thesis we looked at the problem of generalizing methods for handling lattice walk enumeration in many dimensions and with more general constrants, as well as models with interactions. In the earlier chapters we used refined notation and a new perspective of applying operators to functions and functional equations. The result was that we were able to derive the functional equations for $d$-dimensional CLASSIC models with ease. This allowed us to generalize the methods to derive a functional equation for a much more general class of models. This is one more step towards finding out if we may automatize the solutions and classification of more complex lattice walk models. In that vein, we were able to extend the algebraic and obstinate kernel methods to lattice walk models with interactions, although there is still a fair amount of work that needs to be done. First, the algebraic kernel method does not work in a lot of cases of finite groups when the model has interactions, and in those cases that it does work, it does not manage to eliminate the $\Qf{0,0}$ term. The resulting formulae still need to be worked through. At best, we hope that in those cases, if the function $\Qf{0,0}$ is D-finite, then the full generating function $Q$ is D-finite too. In the extension of the obstinate kernel method, we were able to find relations between $\Qf{0,0}$ and its various partially-marked versions for two models - the Cartesian and Diagonal models. However, we were not able to crack the Full model. It also remains to be seen if the cases with less transformations preserving the admissibility of the functions $Q_i^0$ can also be tackled. The problem of solving the functional equation for more generalized models is wide open.

\section{Future Research}
%================================

The future research can be broken down into several over-arching ideas.

\subsubsection{Algebraic kernel method}
\begin{itemize}
	\item In the cases in this thesis, determine we can deduce information about the D-finiteness of $Q$ with respect to the D-finiteness of $\Qf{0,0}$.
	\item Determine if it can be extended to higher-dimensional CLASSIC models with interactions.
	\item Find out if the method can be extened to models with larger steps.
	\item Consider other operators that may annihilate terms of the functional equation and find out if this can be used to find out more information about the generating functions.
\end{itemize}

\subsubsection{Obstinate kernel method}
\begin{itemize}
	\item Explain combinatorially the identities between the marked and partially-marked version of $\Qf{0,0}$. A good place to start would be the one-dimensional models.
	\item In the diagonal model, find a solution for $Q$ in terms of partiall-marked versions of $Q$ and $\Qf{0,0}$.
	\item Find out if there is a similar relationship for $\Qf{0,0}$ in the full model, and in that direction, find out if we can deal with square roots in the extractions of the reduced functional equations.
	\item Solve some of the enumeration problems with other groups, like those of order six.
\end{itemize}

\subsubsection{Kernel methods in general}
\begin{itemize}
	\item Determine if the algebraic and obstinate kernel methods can be combined into one holistic approach. This may involve classifying methods on the number of substitutions made.
	\item Find out the methods can be extened for more generalized models, as in the previous chapter.
\end{itemize}

\subsubsection{Connection with other theory}
\begin{itemize}
	\item Using the Cauchy integral formula, we may rewrite coefficient extractions as complex integrals. This suggests that some of the functional equations may be turned into multidimensional Fredholm integral equations. Perhaps methods from that area can be adapted to the enumeration of lattice walk models. Another clue is the Neumann series solution, which is employed in both theories.
	\item Explore a kind of a Sturm-Liouville theory approch to solving lattice walk enumeration problems. Since we are working with operators and functional equations, it is perhaps possible to find some suitable inner products, where the operators will be self-adjoint. We hope that solutions of the functional equations may be written in terms of eignefunction expansions of the operators involved.
	\item Can the functional equations with operator form be used to find asymptotics for the generating functions involved?
\end{itemize}
