\section{Groups for walks with small steps}
%========================================

Suppose that the random walk model has a step polynomial $S$ in the variables $x_1,\ldots, x_d$. We are interested in the bi-rational transformations that leave the kernel $K = 1 - tS$ intact. For some $x = x_k$ we have bi-rational transformations sending $g: x \mapsto y$ that preserse $K$. That is $K(y) = K(x)$. Expanding the definition we have
\begin{align}\begin{split}
		1- tS(y) &= 1- tS(x)\\
		S(y) &= S(x)\\
		S_{\um 1}\ol{x} + S_1 x & = S_{\um 1} \ol{y} + S_1 y\,.
\end{split}\end{align}
Because of this equation it's equally valid to speak of the birational transformations preserving $S$. Collecting terms and simplifying yields
\begin{align}
	(S_{\um 1}-S_1 xy)(x-y) = 0\,.
\end{align}
There are cases here. If both $S_{\um 1},S_1$ are zero the equation is trivially valid and $g$ can be anything. When exactly one is zero then the equation only has the trivial solution $y = x$. When neither is zero we have the two solutions $y= x$ and $y = \ol{x}S_{\um 1}/S_1$ in which case we say that the transformation is nontrivial. That is we define $g_k = \ol{x}_k S_k^{\um 1}/S_k^1$ whenever we have a nontrivial transformation. Note that
\begin{align}
	g_k^2(x_k) = g_k\left({S_k^{\um 1}}{x_kS_k^1}\right) = x_k
\end{align}
so these transformations are involutions. We can define a group $G_S$ of the nontrivial transformations.
\begin{definition} Let $G = G_S$ be the group generated by the nontrivial transformations $g_k$.
\end{definition}
In the case where the transformation on $x$ is trivial there is something we can say about the random walk model. We use the operator $E = 1 - \ext{\ol{x}}$ to gain information on the generating function $Q$. Since $Q$ only has non-negative powers of $x$ in its expansion $EQ = Q$. However in the master functional equation we have
\begin{align}
	ESQ = SQ - \ol{x}(S_{\um 1}Q_1 + S_0 Q_0 + S_1 Q_{\um 1})= SQ - \ol{x}(S_{\um 1}Q_1 + S_0 Q_0)\,.
\end{align}
We have several cases.
\begin{itemize}
\item[1)] If $S_{\um 1} = 0$ and $S_1 = 0$, $S = S_0$ and therefore $ESQ = S_0EQ = S_0Q$ so the functional equation doesn't "see" the variable $x$.
\item[2)] If $S_{\um 1} = 0$ and $S_1 \neq 0$ then
\begin{align}
	ESQ = SQ - \ol{x}(S_{\um 1}Q_0 + S_0 Q_{\um 1}) = SQ
\end{align}
since $Q_{\um 1} = 0$ so the extraction doesn't see the variable $x$. This is equivalent to saying that even though we are working in the positive orthant we can relax the constraint for the $x$ to the whole space since there are no steps going back in that direction. The variable $x$ is still present in the functional equation. If we have no steps that stay in the $x = 0$ hyperplane then $x$ essentially acts as a parameter in the problem and we can ignore it. Otherwise we'll have
\begin{align}\begin{split}
	LESQ = LSQ &= (1+b[x^0])SQ \\&= SQ + b(S_{\um 1}Q_1+S_0Q_0+S_1Q_{\um 1}) \\&= SQ + bS_0Q_0 \neq SQ\,.
\end{split}\end{align}
\item[3)] If $S_{\um 1}\neq 0$ but $S_1 = 0$ then $ESQ$ is nontrivial but since we cannot take any steps away from the $x = 0$ hyperplane we can eliminate the $S_{\um 1}$ term in the analysis of the problem.
\end{itemize}
In all the cases the random walk model behaves as if $S_{\um 1} = 0$. In the non-interacting version of the problem we can fully ignore the $x$ coordinate in the analysis since it acts like a parameter. The problem is essentially one of lower dimension. In the interacting case we have a bit extra because of the marking operator. In either case we'll define the dimension of the group to be the number of nontrivial generators.
\begin{definition} Let the \emph{dimension} of the model or the group be the number of nontrivial generators of $G_S$ in the defining representation.
\end{definition}
Without loss of generality we will speak of models set in $d$ dimensions that have a full set of generators. Firstly, we can easily show that there are infinitely many different group sizes that are manifested among the different dimensions. Let $S$ be a $(d-1)$-dimensional model with group $G$ of largest finite order (number of elements) for that dimension. Set this model in $d$ dimensions and define a new model $S' = S(x_d+\ol{x}_d)$. This model has a nontrivial generator $g_d$ that $S$ lacks. Therefore the group $G'$ of this new model satisfies
\begin{align}
	G' \cong G \times \langle g_d \rangle
\end{align}
and $|G'| = 2|G|$ and continuing in this manner allows us to write an infinite sequence of distinct groups. That is, not only are there infinitely many distinct groups but also, there is a group in $d$ dimensions not encountered before in $(d-1)$ dimensions (neither in order nor structure). For example the orders of the finite groups set in 2 dimensions are 1, 2, 4, 6 and 8. So in 3 dimensions we have groups of order 1, 2, 4, 6, 8, 12 and 16 at least. In fact Steve's paper shows that there are even more - of orders 24 and 48 too.

This discussion would be short without delving into the subject of Coxeter groups. The $d$-dimensional groups defined above are Coxeter groups - a generalization of the dihedral groups encountered in dimension 2 random walk models. Coxeter groups are defined as
\begin{align}
	G = \langle r_1,\ldots, r_d |(r_ir_j)^{m_{i,j}} = 1\rangle
\end{align}
where $m_{i,i} = 1$ and $m_{i,j} \ge 2$ for all $i\neq j$, and $m_{i,j}$ could also be infinite. We can call these $r$'s reflections. When $m_{i,j} = 2$ the reflections commute. Also $m_{i,j} = m_{j,i}$. The \emph{rank} of $G$ is the number of generators of in this specific representation of $G$. Often $G$ will have more than one representation with different numbers of generators. So in our discussion of groups for random walks with small steps the rank of $G$ is the dimension of the model. We can draw a graph for each Coxeter group by the following procedure.
\begin{itemize}
\item Label vertices with the generators of $G$.
\item Connect the vertices $g_i$ and $g_j$ if $m_{i,j} \ge 3$.
\item Label the edge with $m_{i,j}$ if $m_{i,j}\ge 4$.
\end{itemize}
If the graph has different components, the Coxeter group factors as a direct product of Coxeter groups represented by the individual components. We can see this in terms of the step polynomial $S$. Suppose that $S$ factors as
\begin{align}
	S = T(x_1,\ldots,x_k)R(x_{k+1},\ldots,x_d)\,.
\end{align}
For a fixed $1 \leq i \leq k$ we have
\begin{align}
	S_i^j = [x_i^j]S = R[x_i^j]T = R T_i^j
\end{align}
and therefore
\begin{align}
	g_i(x_i) = \ol{x}_i\frac{T_i^{\um 1}R}{T_i^1R} = \ol{x}_i\frac{T_i^{\um 1}}{T_i^1}\,.
\end{align}
Similarly if $k+1\leq j\leq d$ then
\begin{align}
	g_j(x_j) = \ol{x}_j\frac{R_i^{\um 1}}{R_i^1}\,.
\end{align}
Clearly
\begin{align}
	g_ig_j = g_jg_i
\end{align}
since they don't interfere with each other. Since $i$ and $j$ were arbitrary, this means that the generators from different sets commute and the Coxeter graph of the group factors into two pieces. We can write
\begin{align}
	G_S = G_T \times G_R\,.
\end{align}
where the subscripts highlight which parts of $S$ they groups are generated by. This factoring also allows us to write the generating function $Q$ as a Hadamard product of lower-dimensional generating functions. We can call each component of the graph a prime model. We can say that a simple small component is one whose group doesn't split nontrivially (its graph has one component).

\subsection{Walks with small steps}
%=======================================
At the core of the Algebraic Kernel method we have the idea that we can apply group actions from $G$ onto the master functional equation and obtain nontrivially different equations for each $g\in  G$. After we sum these equations in a nice way we manage to eliminate the functions $Q_1^0,Q_2^0$ and $\Qf{0,0}$ and their orbits leaving only the orbit of the kernel term $KQ$ and a term on the right-hand side. What makes this possible is pre-multiplying the whole equation by $x_1\ldots x_2$. This also works in higher dimensions as we'll show later. Although the generalization has been done before ZZCITEZZ we will present it in a compact and easy to generalize way. Instead of thinking just in terms of equations and summing them as in ZZCITEZZ we'll encapsulate the process in an operator $D_G$ that will take the functional equation and eliminate the terms we don't want by applying the group actions in a nice way. We start by defining $D_G$ so as to do the same thing as in ZZCITEZZ in order to formalize the process.
\begin{definition} Let $G$ be a group represented and generated by $g_k$'s preserving the kernel $K$ for a model for small steps. Then let $D_G$ be the operator defined as
\begin{align}
	D_G = \sum_{g\in G} (-1)^{|g|}g
\end{align}
in the sense of group actions. Here $|g|$ is the sign of the group element $g$.
\end{definition}
In two dimensions we can obtain the whole group by iterating over the two generators 1, $g_i$, $g_jg_i$, $g_ig_jg_i$. It's cleaner to write $g_{iji}$ instead of $g_ig_jg_i$ so we have the following notation
\begin{definition} For a sequence $L = (l_1,l_2\ldots)$ of positive integers define 
\begin{align}
	g_L = g_{l_1l_2\ldots} = g_{l_1}g_{l_2}\ldots
\end{align} 
whenever this makes sense - when the list is finite or when there is a convergence in the case of an infinite list.
\end{definition}
In the case of a finite group in two dimensions we have $(g_1g_2)^n = 1$ for some minimal $n$. This allows us to re-write $D_G$ in a useful way. The following lemma is just a restatement of a result in ZZCITEZZ but in operator notation.
\begin{lemma} For a two-dimensional random walk model with small steps possessing a finite group of order $2n$ and generators $g_1$, $g_2$ we can write the operator $D_G$ as
\begin{align}
	D_G = (1+g_{ij}+\cdots+(g_{ij})^{n-1})(1-g_i)\,.
\end{align}
\end{lemma}
\begin{proof} We can just check the identity by expanding it as
\begin{align}\begin{split}
	D_G &= (1+g_{ij}+\cdots+(g_{ij})^{n-1})(1-g_i)\\
	        &= 1- g_i +g_{ij}-g_{iji} + \cdots - (g_{ij})^{n-1}g_i
\end{split}\end{align}
giving us one of the possible orbits
\end{proof}
Here are some examples of small groups.
\begin{example} When $|G| = 4$ the elements commute so the orbit is $1, g_1,g_{12} = g_{21}, g_2$ and the operator is
\begin{align}
	D_G = 1 - g_1 - g_2 + g_{12} = (1-g_1)(1-g_2)\,.
\end{align}
When $|G| = 6$ the orbit is $1,g_1,g_{21},g_{121}=g_{212},g_{12},g_2$. We can write the operator as
\begin{align}\begin{split}
	D_G &= (1+g_{12}+g_{1212})(1-g_1) \\
	&=  1+g_{12}+g_{1212} - g_1 - g_{121} - g_{12121} \\
	&= 1 -g_1 - g_2 + g_{12}+g_{21}-g_{121}\,.
\end{split}\end{align}
\end{example}
We can generalize the lemma for a multi-dimensional group $G$.
\begin{lemma}Let $\mc{M}$ be a model with small steps in $\ze^d$ and let $G$ be its asociated group. For a nontrivial generator $g_k$ we can write the operator as $D_G = D_H(1-g_k)$ for a subgroup $H$ of $G$.
\end{lemma}
\begin{proof} Simpler proof: each element in the fixed representation of $G$ either ends in $g_k$ or doesn't. We have a bijection between the two sets by using the involution $g_k$ applied on the right. The elements ending in $g_k$ have opposite parity to those not ending on $g_k$ so we can split $G$ into two parts $H$ and $Hg_k$. We can split the defining sum into two parts and keep track of the sign changes via $e_g = (-1)^{|g|}$. We have
\begin{align}\begin{split}
	D_G &=\sum_{g \in H} e_g g + \sum_{g \in Hg_k} e_g g\\
	&=\sum_{g \in H} e_g g + \sum_{g \in H} (-1)e_g g g_k\\
	&= \left(\sum_{g \in H} e_g g\right)(1-g_k)\\
	&= D_H(1-g_k)\,.
\end{split}\end{align}
I'll have to provide a different proof maybe. Take $H = G/\langle g_k \rangle$. Since $g_k$ is of order 2 the resulting group has $|G|/2$ elements. Consider the elements of $G$ that commute with $g_k$, that is $h\in G$ where $g_k h = h g_k$. Multiplying by $g_k^{\um 1} = g_k$ we see that $h = g_k h g_k$. Let $H$ be the subgroup of $G$ generated by those elements. There are two cosets $H$ and $Hg_k$.
\end{proof}
\begin{lemma} The operator $D_G$ eliminates the term $t S_I^{-\one}Q_I^\oo$ for $I \neq \emptyset$.
\end{lemma}
\begin{proof} By the previous lemma, for some $i\in I$, $D_G(t S_I^{-\one}Q_I^\oo) = D_H((1-g_i)t S_I^{-\one}Q_I^\oo)) = D_H(0) = 0$ since the variable $x_i$ is not present in the function.
\end{proof}
We obtain the $d$-dimensional generalization to the 2-dimensional Algebraic Kernel method.
\begin{theorem} For a model with small steps we have
\begin{align}
D_G(\mon xd KQ) = D_G(\mon xd)
\end{align}
where the RHS may be zero sometimes.
\end{theorem}
\begin{proof} When we multiply the master functional equation by $\mon xd$ we obtain a lot of terms like the ones in the lemma. The only term that survives the application of $D_G$ on the LHS is $\mon xd KQ$ and the equality follows.
\end{proof}

The authors in ZZCITEZZ have found that sometimes the AK method fails. That is $D_G(\mon xd) = 0$ and the equation doesn't give us any new information. We can generalize this as follows.

\begin{corollary} Suppose that there is a group element $h \in G$ with odd parity that permutes the variables $x_1,\ldots,x_d$ in some way and has order 2. Then the regular Algebraic Kernel method fails. That is
\begin{align}
D_G(\mon xd KQ) = 0\,.
\end{align}
\end{corollary}
\begin{proof} Since $h$ is an involution the same method applies as before and we can factor $D_G = D_H(1-h)$ for some $H \subseteq G$. The action $1-h$ eliminates the monomial $\mon xd$. ZZCITEZZ
\end{proof}

\begin{example} The 2D models where the Algebraic Kernel method fails in its straight-forward construction are precisely those where we have a permutation as in the corollary. That is $h(x_1,x_2)= h(x_2,x_1)$ and $|h| = 3$.
\end{example}

\begin{example} In ZZCITEZZ there is a model with group size 12 for which the Algebraic Kernel method fails. For that model one of the group element is a permutation of two of the variables - in that case $x_2$ and $x_3$. Strangely enough $G$ contain the group seen in the previous example for the variables $x_2$ and $x_3$. This means that every higher-dimensional model that has group $G$ containing the group above will fail in the regular Algebraic Kernel method.
\end{example}
A natural question is to consider taking $D_H$ instead of $D_G = D_H(1-h)$ and checking if we can perfom a half-orbit summation in general. The answer is yes. The operatro $D_H$ eliminates some of the $Q$ variables and introduces others but the result is a function symmetric under permutation by $h$. One may hope to perform a method analogous to the half-orbit summation method to prove algebraicity or D-finiteness.

\begin{example}There is another way we can prove that $D_G$ does what it advertises. We start with the kernel form $EKQ = 1$ where we make the substitution $Q = W/(\mon xd K)$ and re-write the equation as
\begin{align}
	E' W = \mon xd,\quad\quad E_k' = 1 - [x_k^0]\,.
\end{align}
\end{example}
Therefore
\begin{align}
	W = \mon xd -(1-E')W=\mon xd - \sum_{\emptyset \neq I \subseteq [d]}W_I^\oo\,.
\end{align}
We immediately see that
\begin{align}\begin{split}
	D_G(\mon xd KQ) = D_G(W) &= D_G\left(\mon xd - \sum_{\emptyset \neq I \subseteq [d]}W_I^\oo\right) \\&= D_G(\mon xd)
\end{split}\end{align}
since the $W_I^\oo$ terms have missing variables. Let's think about this for a moment. The form of $W$ is the same for all random walk models with small steps so if there are two models whose operators both annihilate expressions of the form $W_I^\oo$ for all non-empty $I\subseteq [d]$ then both models have equations of the above type with each other's operators! In particular we may take the group $G$ of the highly-symmetric models and apply it via the operator $D_G$ for any other model and we obtain an equation of the above type! We'll look into this further.
\begin{definition} Let $g_k(x_k) = \ol{x}_k$. Define the operator $\Delta_k = 1 - g_k$ for this specific $g_k$. Let $\Delta = \Delta_1\cdots \Delta_d$.
\end{definition}

\begin{theorem} Let $G$ be the group generated by $g_k(x_k) = \ol{x}_k$ for $1 \leq k \leq d$. Let $\Delta_k = 1 - g_k$. Then we have $D_G = \Delta$
and
\begin{align}
	\Delta(\mon xd KQ) = \Delta(\mon xd) = (x_1 - \ol{x}_1)\cdots(x_d-\ol{x}_d)
\end{align}
for any small step random walk model in dimension $d$ with no interactions.
\end{theorem}
\begin{proof} It's enough to see that $\Delta$ annihilates any term of the form $W_I^\oo$ for $I \neq \emptyset$. Since the operatos $\Delta_k$ commute we only need to apply one $\Delta_i$ for some $i$ first and find
\begin{align}
	\Delta_i(W_I^\oo) = W_I^\oo - g_i(W_I^\oo) = 0
\end{align}
since the term is missing variable $x_i$. The rest follows by linearity.
\end{proof}
This won't help show a specific model has a D-finite solution because in general we cannot factor out the $K$ term from the LHS. However the idea is important and it allws us to write the following.
\begin{corollary} All random walk models of dimension $d$ satisfy the functional equation 
\begin{align}
E'(\mon xd KQ) = \mon xd\,.
\end{align}
Therefore the only difference between the models is in the initial conditions that go with this functional equation.
\end{corollary}

We'll extend these ideas in the next section but first we'll look into generalizing the ideas involved in the algebraic kernel method.
\begin{definition} Let $G$ be a group acting on $\row xd$. Then we define a weighted orbit summation operator to be any operator of the form
\begin{align}
	D = \sum_{g\in G}R_g g
\end{align}
where $R_g$ are functions in the variables $\row xd$.
\end{definition}

The orbit summation operator is an example of this with $R_g' = 1$ for the groups considered so far. We can capture various strategies in this notation
\begin{example} Since the Algebraic Kernel method fails to give a nice result when $G$ contains permutations we may try to apply the operator $D_G$ on a slightly different equation - one where we multiply the whole equation by a function $T \neq \mon xd$. For a function $f$ we have
\begin{align}
	D_G(Tf) = \sum_{g\in G}g(T f) = \sum_{g\in G} ( g(T)) g(f) =  \sum_{g\in G} R_g g(f)\,.
\end{align}
The situation of applying $D_G$ on $T$ times the functional equation is the same as applying a weighted orbit summation operator on the original functional equation with weights $g(T)$ for $g \in G$.
\end{example}
We may also consider the strategy of applying a weighted operator several times in the hopes of obtaining an easier equation to work with. However as we shall see this is no different than looking at a weighted operator in the first place. This is because $G$ is a group and the composition $D_G^2$ leads to another weighted operator. Also, since some of the operators $D_G$ have nontrivial kernels they are not invertible, so the set of operators is not a group. Howeve we can show that the set is a monoid under composition.
\begin{prop} For a group $G$, the set of weighted orbit summation operators form a monoid under composition.
\end{prop}
\begin{proof} Since $G$ is a group we have an identity element 1 which can also be considered as a weighted orbit summation operator with $R_g = 0$ for all $g\neq 1$ and $R_1 = 1$. Thus the set of operator has an identity element. Since composition of operators is associative just need to check that the set of operators is closed under composition. We have
\begin{align}
	D_1D_2 = \sum_{g\in G}\sum_{h\in H} R_g gT_h h = \sum_{g\in G}\sum_{h\in H} R_g T_{gh} gh \sum_{g\in G}(\sum_{h\in H} R_{gh_{\um 1}} T_{g}) g
\end{align}
which is also an operator of this form once we collect terms corresponding to the same group elements.
\end{proof}

We hope to apply a weighted operator $D$ to a problem in order to gain more insight into the structure of the generating function $Q$. Since all models with small steps and finite groups also have a regular orbit summation operator we have two main interesting cases to investigate.
\begin{itemize}
\item[(1)] When is $D_G(\mon xd) = 0$ and can we find weights so that a new operator $D$ that acts like $D_G$ but spares $\mon xd$?
\item[(2)] Can we create a useful orbit summation operator when $G$ is infinite?
\end{itemize}
We can answer the first question in the negative when it comes to un-marked random walk models. In general there is no other weighted orbital operator except the one with weights $R_g = 1$ that doesn't also eliminate $\mon xd$. The second case remain unclear.

Here is the strategy we'll employ. If we apply the operator $D$ on the master functional equation we need to eliminate all terms except $KQ$. That is $D$ needs to annihilate all the $Q$ terms that are missing variables. It is enough to work on the fundamental functional equation for $W = \mon xd KQ$. To go back to the master functional equation case we recognize that $\mon xd$ just make it a weighted operator and we can remove the weight by pre-dividing by $\mon xd$. The resulting operator is also weighted.

\begin{lemma}A weighted operator $D$ exists such that $D( KQ) = D(1)$ if and only if a weighted operator $D'$ exists such that $D'(f_I^\oo)$ for generic functions $f_I^\oo$ that are missing the variables indexed by $I$, for all $I$.
\end{lemma}
\begin{proof} The discussion above provides the direction from left to right for $f = W$. To prove it for generic functions $f$ it suffices to note that $f_I^\oo$ and $f_J^\oo$ are independent from each other if $I \neq J$. That is, $D(f_I^\oo)$ and $D(f_J^\oo)$ do not share terms. The converse direction is proved by setting $f = W$ and setting $D = D'\mon{\ol{x}}{d}$ where $(D'\mon{\ol{x}}{d} )(f) = D'(\mon{\ol{x}}{d} f)$.
\end{proof}
This essentially turns this into a linear algebra problem. We just need to apply $D$ on generic functions $W_I^\oo$ that are missing the variables indexed by $I$, collect the different results and make their coefficients zero. That is, for every $f = W_I^\oo$ we look at the orbit
\begin{align}
	\orb_G(f) = \{g(f)| g \in G\}
\end{align}
and collect coefficients in
\begin{align}
	0 = D(f) = \sum_{g\in G}R_g g(f) = \sum_{f' \in Orbit(f)} R_g' f'
\end{align}
where we set
\begin{align}
	R_g' = \sum_{\substack{g(f) = f'\\g\in G}} R_g = 0\,.
\end{align}
Thus we obtain a linear system of $|\orb_G(f)|$ equations in $|G|$ unknowns. Of course we can do this for all $2^d - 1$ terms $f = W_I^\oo$ and hopefully obtain a system with a nontrivial solution. Here is a simple example
\begin{example} In $d = 2$ dimensions we have the generic functions $W(0,0) = const$, $W(0,x_2)$, $W(x_1,0)$ where at least one variable is missing. We can write them as $1, f(x_1), f(x_2)$. Now we consider the group generated by $g_k(x_k) = \ol{x}_k$
\begin{align}
	G = \{1, g_1, g_2, g_{12} = g_{21}\}\,.
\end{align}
We'll write the operator $D$ as 
\begin{align}
	D = R - R_1 g_1 - R_2 g_2 + R_{12} g_{12}\,.
\end{align}
Consider the different orbits. The one with the constant is trivial since the function doesn't change under the group action. Next we have
\begin{align}
	\orb_G(f(x_1)) = \{f(x_1),f(\ol{x}_1),f(\ol{x}_1), f(\ol{x}_1)\} = \{f(x_1),f(\ol{x}_1)\}
\end{align}
and similarly
\begin{align}
	\orb_G(f(x_2)) = \{f(x_2),f(\ol{x}_2)\}\,.
\end{align}
This means we have the equations
\begin{align}
	R - R_1 &+ R_2 - R_{12} = 0\,,\\
	R = R_2, &\quad R_1 = R_{12}\,,\\
	R = R_1, &\quad R_2 = R_{12}\,.
\end{align}
Folowing the implications provided from these operators we find $R= R_1 = R_2 = R_{12}$. The simplest choice is to set $R = 1$ and we find that every weighted orbit summation operator for this group $G$ must be trivially-weighted if it were to annihilate generic functions with missing variables.
\end{example}
\begin{definition} If all the weights are the same we call a weighted operator trivial. We can also call trivial operators unweighted or regular.
\end{definition}
\begin{lemma} Let $G$ be a finite group with $d$ generators for a random walk model in $d$ dimensions with small steps and no interactions. Then any orbital operator is trivial.
\end{lemma}
We need to check this proof.
\begin{proof}It is enough to show that $D(W_k^0) = 0$ for all $k$ implies that the operator is trivial. To this end suppose that $D(f) = 0$ where $f = W_k^0$. Then we can partition the group $G$ as before into sets $H$ and $Hg_k$. We see that $hg_k (f) = h(f)$ so the orbit of $f$ contains at most $|G|/2$ elements. However these elements must all be distinct otherwise they would come from the same operations but the group elements in $H$ are all distinct. So $|\orb(f) = |G|/2$. This means that we have the equations $R_h = R_{hg_k}$ for every $h \in H$. Once we go through every $k$ we have overlaps $R = R_1 =\cdots = R_d$ and $R_1 = R_{12} = R_{13}$ etc. This means that all the $R$'s are the same and the operator is trivial.
\end{proof}
This shows that in general there is no clever weighted summation operator that also satisfies the condition $D(\mon xd) \neq 0$. However, the idea will be fruitful in that we may find nontrivial partial solution in the interacting case.

%=======================================
\subsection{Walks with unconstrained steps}
%=======================================
We may go through the process again but this time we take
\begin{align}
	Q = \frac{W}{x_{[d]}^N K}
\end{align}
where $N_k$ is the maximum negative size of steps in the set $\mc{S}$ in the direction $x_k$ or in other words the maximum $N_k$ for which $S_k^{N_k}$ is non-zero. Then the operators that keep the walks in the quarter plane are
\begin{align}
	E_k = 1 - \sum_{i=1}^{N_k} \ext{\ol{x}_k^i}\,.
\end{align}
Their conjugates are
\begin{align}
	E_k' = x_k^{N_k} E_k \ol{x}_k^{N_k} = 1 - \sum_{i=0}^{N_k-1}\ext{x_k^i} = 1 -\mc{E}_k
\end{align}
and so in the kernel equation we obtain
\begin{align}
	x_{[d]}^N = x_{[d]}^N E \ol{x}_{[d]}^N W = E' W = W +  \sum_{\emptyset \neq I\subseteq [d]} (-1)^{|I|} \mc{E}_I(W)\,.
\end{align}
Here we have various powers $x_k^i$ along with terms with $x_k = 0$ for $k \in I$. So if we seek an operator $D$ that does the same job as the orbit summation operator we need $D$ to annihilate all the terms with $x_k$'s missing in $W$ on the RHS. So then we'll have
\begin{align}
	D(x_{[d]}KQ) = D(W) = D\left(x_{[d]}^N-\sum_{\emptyset \neq I\subseteq [d]} (-1)^{|I|} \mc{E}_k(W)\right) = D(x_{[d]}^N)\,.
\end{align}
In other words we want $D$ to behave (in some sense) similarly to the derivative
\begin{align}
\del_{[d]}^N = \del_1^{N_1}\cdots \del_d^{N_d}\,.
\end{align}
This suggests some definitions.
\begin{definition}For a sequence $N = (N_1,\ldots, N_d)$ of positive integers we say that a model $\mc{M}$ is of type $N$ that the longest step in $\mc{S}$ in the negative $k$-th direction has length $N_k$ in that coordinate. In particular we may say that a model is of type $n$ if $N_k = n$ for all $k$.
\end{definition}
For example, full random walks with small steps are of type 1.
\begin{definition}For sequences $N = (N_1,\ldots, N_d)$ and $M = (M_1,\ldots, M_d)$ of positive integers we say that a model $\mc{M}$ is of type $(N,M)$ if it's of type $N$ and the longest step in $\mc{S}$ in the positive $k$-th direction has length $N_k$ in that coordinate. In particular we may say that a model is of type $(n,m)$ is of type $n$ and $M_k = m$ for all $k$.
\end{definition}
For example, full random walks with small steps are of type $1,1$. The notation is still a little awful. Anyway, it allows us to write things in the following form
\begin{theorem} A random walk model of type $N$ satisfies the functional equation
\begin{align}
	E'W = \fullx xdN
\end{align}
where $E' = \fullx xdN E \fullox xdN$ and $W  = \fullx xdN KQ$.
\end{theorem}

\begin{corollary} For a random walk model of type $N$ the generating function $Q$ for the non-interacting case satisfies the PDE
\begin{align}
	\fullx{\del}dN\left(\fullx xdN KQ\right) = 1
\end{align}
and is therefore D-finite in the $x$ variables.
\end{corollary}
Here $\fullx{\del}dN$ is an example of operator $D$ that kills off all the unnecessary terms and doesn't kill off $\mon xd$. It's possible to discuss weighted operators in this setting too but the situation becomes more complicated. However we may investigate type $(N,M)$ problems by finding a suitable model whose orbital operator is nice enough. This will show that all type $(N,M)$ satisfy an orbital equation with that particular operator, not just a PDE. 

\begin{example} Consider the random walk model of type $(N,N)$ with $S = \sum_{k=1}^d \ol{x}_k^{n_k} + x_k^{n_k}$. Its group $G$ will is generated by the elements of groups $G_k$ with $2n_k$ elements each - each of the elements $g_{k,j,l} = \omega_{n_k}^jx_k^l$ where $\omega_{n_k} = \exp(2\pi i/n_k)$ and $l\in\{-1,1\}$. These elements commute and allow us to find an orbital operator that annihilates all terms on the LHS except  $\fullx xdN KQ$ and also spares the $\fullx xdN$ term on the RHS.
\end{example}

%====================================
\section{Interacting Models}
%====================================
It is natural to consider extending the algebraic kernel method to one working for interacting models but we quickly see that the regular orbit summation operator is not sufficient. This is where the power of the weighted orbital summation operators starts to show. The analysis for two-dimensional models is particularly nice because we end up having the same number of equations as unknowns and we are able to find the required weights. The linear systems can be written as matrix equations where the determinant of the matrix tells us when we have a useful orbit summation operator. In the end the method doesn't extend fully because we do not eliminate the $\Qf{0,0}$ term. The D-finiteness of the full generating function $Q$ depends on the D-finiteness of the function $\Qf{0,0}$. Also we hope to say something about the initial goal of establishing relationship between the full and partial interactions for a given model. We'll only consider the interesting finite cases with 2 nontrivial generators. The group $G$ has order 4, 6 or 8 and the functional equation in two dimensions is
\begin{align}
	KQ  - K_1 Q_1^0 -  K_2 Q_2^0 + K_{1,2}Q_{1,2}^{0,0} = \alpha\,.
\end{align}
%====================================
\subsection{Groups of order 4}
%====================================
From a previous section we found that
\begin{align}
	D_G = 1-g_1-g_2+g_1g_2 = (1-g_1)(1-g_2) = \Delta_1\Delta_2
\end{align}
where we defined $\Delta_i = 1- g_i$. In the non-interacting orbit summation method we had a direct application of $D_G$ on the equations to perform the required cancellations. Here we will attempt to do something similar. Since the cancellations don't happen automatically if we use $D_G$ directly, we'll instead obtain a linear system of equations by applying the group operations on the original functional equation. Then we'll use linear algebra to find a solution where our variables will be the ones we wish to eliminate $Q_i^0$ and their images under the group actions. If the associated matrix has non-zero determinant we have a unique solution and unfortunately we won't be able to eliminate variables. However there are some cases where the determinant will be zero. Because of symmetry we expect to be able eliminate the desired variables. The group operations commute so we have
\begin{align}
	g_i Q_i^0 = Q_i^0,\quad g_ig_j Q_i^0 = g_j Q_i^0
\end{align}
and therefore we have the variables that we wish to eliminate
\begin{align}
	E = \{Q_1^0,Q_2^0,g_2Q_1^0,g_1Q_2^0\}\,.
\end{align}
This is looking promising since we have four equations and four unknowns that we wish to eliminate. We re-write the original equation in a format centered on these variables
\begin{align}
	 K_1 Q_1^0 +  K_2 Q_2^0 = KQ + K_{1,2}Q_{1,2}^{0,0} -\alpha = \beta\,.
\end{align}
For brevity let $g_{12} = g_1g_2$
\begin{table}[H]
\caption{Effects of group actions $g\in G$ on $Q_1^0$ and $Q_2^0$.}
\label{tbl:actions4}
\centering
\begin{tabular}{ccc}
\toprule
	Group action & Effect on $Q_1^0$ & Effect on $Q_2^0$\\
\midrule
	$1$ & $Q_1^0$ & $Q_2^0$\\
	$g_1$ & $Q_1^0$ & $g_1Q_2^0$ \\
	$g_2$ & $g_2Q_1^0$ & $Q_2^0$ \\
	$g_{12}=g_{21}$ & $g_2Q_1^0$ & $g_1Q_2^0$ \\
\bottomrule
\end{tabular}
\end{table}
Therefore we have the equations
\begin{align}
	 K_1 Q_1^0 +  K_2 Q_2^0 &= \beta\,,\\
	 g_1K_1 Q_1^0 + g_1K_2 g_1Q_2^0 &= g_1\beta = \beta_1\,,\\
	 g_2K_1 g_2Q_2^0 + g_2K_2 Q_2^0 &= g_2\beta = \beta_2\,,\\
	 g_{12}K_1 g_2Q_1^0 + g_{12}K_2 g_1Q_2^0 &= g_{12}\beta = \beta_{12}\,.
\end{align}
Using the order of variables in $E$ we can write the associated matrix $M$ of this linear system as
\begin{align}
	M_4 = \begin{bmatrix}
	K_1 & K_2 & 0 & 0 \\
	g_1 K_1 & 0 & 0 & g_1 K_2\\
	0 & g_2 K_2 & g_2 K_1 & 0\\
	0 & 0 & g_{12}K_1 & g_{12} K_2
	\end{bmatrix}
\end{align}
Its determinant is
\begin{align}\begin{split}
	\det M_4 &= K_1 g_{12}K_1 g_1K_2g_2K_2 -g_1K_1g_2K_1K_2g_{12}K_2\\
	& = K_1 g_{12}K_1 g_1K_2g_2K_2  -g_1(g_1K_1g_{12}K_1g_1K_2g_{2}K_2)\\
	&=\Delta_1  (K_1 g_{12}K_1 g_1K_2g_2K_2)\\
	&=\Delta_2 (g_1 K_1 g_2 K_1K_2 g_{12} K_2 )
\end{split}\end{align}
where the last equation comes from doing the process in the same way but with $g_2$ instead.

%====================================
\subsubsection{When is $\det M_4 = 0$?}
%====================================

Now our task is to find where this determinant is zero. Clearly the expression within each $\Delta$ must be in the kernel of the operator. To that end let's find when that happens. For a Laurent polynomial $f$ in the variables $x_i$ and $t$ we have
\begin{align}
	\Delta_k f = \sum_n f_n (1-g_k)x_k^n = \sum_n (f_n - f_{-n}\mu_k^{-n})x_i^n
\end{align}
where $\mu_k = S_k^{\um 1}/S_k^1$. This implies that
\begin{align}
	f_{n} &= f_{-n} \mu_k^{-n}\\
	f_{n} (S_k^1)^n &= f_{-n}(S_k^{\um 1})^n
\end{align}
for all $n \in \ze$. It's not clear if this will help us. However the models that exhibit groups of order 4 have at least one symmetry across a line - either vertical or horizontal symmetry. WLOG let the model have vertical symmetry. That is 
\begin{align}
	g_1(x_1) = x_1, \quad g_1(S_2^i) = S_2^i,\quad g_1(S_1^i) = S_1^{-i}\,.
\end{align}
This allows us to compute some things. For example
\begin{align}
	g_1 K_2 &= c_2 - t\ol{x}_2 g_1S_2^{\um 1} = c_2 - t\ol{x}_2 S_2^{\um 1} = K_2\,,
	g_1g_2K_2 = g_2 g_1 K_2 = g_2\,.
\end{align}
Therefore $\Delta_1$ fixes both $K_2$ and $g_2K_2$.
We see that the determinant is
\begin{align}
	\det M_4 = \Delta_1  (K_1K_2 g_{12}K_1 g_2K_2) = K_2 g_2K_2 \Delta_1  (K_1 g_{12}K_1)\,.
\end{align}
This is zero if and only if $\Delta_1  (K_1 g_{12}K_1) = 0$ so we have
\begin{align}\begin{split}
	0&=\Delta_1  (K_1 g_{12}K_1) \\
	&= K_1g_{12}K_1 - g_1 K_1 g_2 K_2 \\
	&= (c_1-t\ol{x_1}S_1^{\um 1})(c_1-tx_1g_2S_1^{\um 1})-(c_1-tx_1S_1^{\um 1})(c_1-t\ol{x_1}g_2S_1^{\um 1})\\
	&= c_1 t \ol{x}_1 (g_2 S_2^{\um 1} - S_2^{\um 1}) - c_1 t x_1 (g_2 S_2^{\um 1} - S_2^{\um 1})\\
	&= c_1 t (\ol{x}_1-x_1)(g_2 S_1^{\um 1}-S_1^{\um 1})\\
	& = -c_1 t(\ol{x}_1-x_1)\Delta_2(S_1^{\um 1})\,.
\end{split}\end{align}
This is true if and only if
\begin{align}
	g_2 S_1^{\um 1} = S_1^{\um 1}\,.
\end{align}
We have
\begin{align}
	g_2 (\Sf{\um 1, \um 1}\ol{x}_2+\Sf{\um 1,0}+\Sf{\um 1,1}x_2) = \Sf{\um 1, \um 1}x_2 \ol{\mu}_2+\Sf{\um 1,0}+\Sf{\um 1,1}\ol{x}_2\mu_2
\end{align}
and
\begin{align}
	\Sf{\um 1, \um 1}x_2 \ol{\mu}_2+\Sf{\um 1,1}\ol{x}_2\mu_2 = \Sf{\um 1, \um 1}\ol{x}_2+\Sf{\um 1,1}x_2
\end{align}
which can be re-written succinctly as
\begin{align}
	\Sf{\um 1, \um 1} = \mu_2 S_{\um 1,1}\,.
\end{align}
If one of the $S$'s is zero so is the other and therefore by symmetry the model doesn't have diagonal steps. Since we have two nontrivial generators this implies that both $x_2$ and $\ol{x}_2$ are present in $S$, so the model trivially exhibits a symmetry about the $x_1$ axis. If the $S$'s are non-zero this implies $\mu_2$ is a constant and therefore $S_2^{\um 1} = S_2^1$. Again the model exhibits symmetry about the $x_1$ axis. 
\begin{theorem} $\det M_4 = 0$ if and only if the model is highly-symmetric.
\end{theorem}

\begin{corollary} The algebraic kernel method extends to the non-interacting case for $|G| = 4$ if and only if the model is highly-symmetric.
\end{corollary}

We are now ready to attempt using the orbit summation method in the highly symmetric cases. There are 8 such models but only 5 of them have dimension 2. Furthermore 2 of the models are reflections of each other so we are really left with 4 interesting cases - diagonal walks, full walks, full walks minus two horizontal steps. If we are able to eliminate all the variables then we'll be left with a linear relation
\begin{align}
	\gamma \beta- \gamma_1 \beta_1-\gamma_2 \beta_2 + \gamma_{12}\beta_{12} = 0\,.
\end{align}
Here the choice of signs is inspired by the orbit summation operators. Let $\bullet$ and $\ast$ stand for applications of $g_1$ and $g_2$ respectively. First we have $K_2^\bullet = K_2$ and $K_1^\ast = K_1$. Then we let
\begin{align}
	x = Q_1^0\,,\quad y= Q_2^0\,, \quad u= Q_1^{0,\ast}\,,\quad v = Q_2^{0,\bullet}
\end{align}
and
\begin{align}
	a = K_1\,,\quad b = K_1^\bullet\,,\quad c=K_2 \,, \quad d = K_2^\ast
\end{align}
The original equations become
\begin{align}
	\beta &= a x + c y\,,\quad \beta_1 = b x + c v\,,\\
	\beta_2 &= d y + a u\,,\quad \beta_{12} = b u + d v\,,
\end{align}
Therefore the above equation needs to satisfy
\begin{align}\begin{split}
	0 &= (ax+cy)\gamma - (bx+cv)\gamma_1 - (dy+au)\gamma_2 + (bu +dv) \gamma_{12}\\
	   &= (a\gamma-b\gamma_1)x + (c\gamma-d\gamma_2)y + (b\gamma_{12}-a\gamma_2)u + (d\gamma_{12}-c\gamma_1)v
\end{split}\end{align}
and in order to eliminate the variables $x,y,u,v$ we need to make all their coefficients zero. Therefore
\begin{align}
	a\gamma = b\gamma_1\,,\quad c\gamma = d\gamma_2\,, \quad b\gamma_{12} = a \gamma_2,\,,\quad d\gamma_{12} = c\gamma_1\,.
\end{align}
If we set $\gamma = 1$ then $\gamma_1 = a/b$, $\gamma_2 = c/d$ and $\gamma_{12} = (ac)/(bd)$. So we can multiply out by $bd$ to find the relation
\begin{align}
	bd\beta-ad\beta_1-cb \beta_2+ac \beta_{12} = 0
\end{align}
where we have successfully eliminated $Q_1^0, Q_2^0, Q_1^{0,\ast}$, and $  Q_2^{0,\bullet}$. Or written in terms of the $K$'s we have
\begin{align}
	K_1^{\bullet}K_2^{\ast}\beta^{}-K_1^{}K_2^{\ast}\beta^{\bullet}-K_1^{\bullet}K_2^{}\beta^{\ast}+K_1^{}K_2^{}\beta^{\bullet\ast} = 0\,.
\end{align}
We can re-write this equation in the following nicer way.
\begin{theorem} For highly-symmetric models with small steps we have the functional equation
\begin{align}
	\Delta(K_1^\bullet K_2^\ast \beta) = 0
\end{align}
where $\beta = KQ + K_{1,2}Q_{1,2}^{0,0} -\alpha$.
\end{theorem}
We can expand this functional equation to obtain a different form. Towards this end let $K_0 = K_1^\bullet K_2^\ast$. We obtain
\begin{align}\begin{split}
	\Delta(K_0\beta) &= \Delta(K_0(KQ + K_{1,2}Q_{1,2}^{0,0} - \alpha)) \\
	&= \Delta(K_0 KQ) +\Delta(K_0 K_{1,2}Q_{1,2}^{0,0}) - \Delta(K_0\alpha)\\
	&= K\Delta(K_0 Q) + \Delta(K_0 K_{1,2})Q_{1,2}^{0,0} - \Delta(K_0)\alpha
\end{split}\end{align}
where the last line follows since $\Delta$ commutes with $K$ and functions with some variables $x_i$ missing. All that remains is to expand the various quantities involved
\begin{align}
	\Delta g_iK_i = - \Delta K_i = - (c_i-tx_iS_i^{\um 1}-c_i + t\ol{x}_i S_i^{\um 1}) = -t(\ol{x}_i-x_i)S_i^{\um 1}\,.
\end{align}
Therefore
\begin{align}
	\Delta K_0 = \Delta_1 (K_1^\bullet) \Delta_2 (K_2^\ast) = t^2(\ol{x}_1-x_1)(\ol{x}_2-x_2)S_1^{\um 1}S_2^{\um 1}\,.
\end{align}
Next
\begin{align}
	\Delta(K_0 K_{1,2}) = \Delta_1 K_1^\bullet \Delta_2 K_2^\ast K_{1,2} = \Delta_1 K_1^\bullet (K_2^\ast K_{1,2}- K_2 K_{1,2}^\ast)\,.
\end{align}
The quantity in parentheses is
\begin{align}\begin{split}
	&K_2^\ast K_{1,2}- K_2 K_{1,2}^\ast =\\
	=& (c_2-tx_2S_2^{\um 1})(c_1c_2-t\ol{x_1}\ol{x_2}S_{1,2}^{\um 1, \um 1})-(c_2-t\ol{x_2}S_2^{\um 1})(c_1c_2-t\ol{x_1}x_2S_{1,2}^{\um 1, \um 1})\\
	=& c_1c_2tS_2^{\um 1}(\ol{x_2}-x_2) - c_2t\ol{x_2}S_{1,2}^{\um 1, \um 1}(\ol{x_2}-x_2)\\
	=& c_2t(\ol{x_2}-x_2)(c_1S_2^{\um 1}-\ol{x_1}S_{1,2}^{\um 1, \um 1})\,.
\end{split}\end{align}
and thus
\begin{align}\begin{split}
	\Delta(K_0 K_{1,2})  &= c_2t(\ol{x_2}-x_2) \Delta_1 K_1^\bullet (c_1S_2^{\um 1}-\ol{x_1}S_{1,2}^{\um 1, \um 1})\\
	&=c_2t(\ol{x_2}-x_2) \Delta_1 K_1^\bullet (c_1S_2^{\um 1}-\ol{x_1}S_{1,2}^{\um 1, \um 1})\,.
\end{split}\end{align}
To simplify this quantity note that
\begin{align}
\Delta_1 K_1^\bullet c_1 S_2^{\um 1} = c_1 S_2^{\um 1}\Delta_1 K_1^\bullet = -c_1t S_2^{\um 1}(\ol{x}_1-x_1)
\end{align}
and
\begin{align}
	\Delta_1 K_1^\bullet \ol{x_1}S_{1,2}^{\um 1, \um 1} = S_{1,2}^{\um 1, \um 1}\Delta_1 K_1^\bullet \ol{x_1} = c_1 (\ol{x}_1-x_1)S_{1,2}^{\um 1, \um 1}\,.
\end{align}
Finally
\begin{align}
	\Delta(K_0 K_{1,2}) = c_1c_2t(\ol{x}_1-x_1)(\ol{x}_2-x_2)(t S_1^{\um 1} S_2^{-2}-S_{1,2}^{\um 1, \um 1})\,.
\end{align}
Combining terms and simplifying a bit leads us to
\begin{align}
	K\Delta(K_0 Q) = \alpha t(\ol{x}_1-x_1)(\ol{x}_2-x_2)(tS_1^{\um 1}S_2^{\um 1} - b_1b_2(tS_1^{\um 1}S_2^{\um 1}-\Sf{\um 1, \um 1})\Qf{0,0})
\end{align}
\begin{corollary} For a highly-symmetric model with $K_0 = K_1^\bullet K_2^\ast$ we have the functional equation
\begin{align}
	K\Delta(K_0 Q) = \alpha t(\ol{x}_1-x_1)(\ol{x}_2-x_2)(tS_1^{\um 1}S_2^{\um 1}(1 - b_1b_2\Qf{0,0}) + \Sf{\um 1, \um 1}\Qf{0,0})\,.
\end{align}
\end{corollary}
%====================================
\subsection{Groups of order 6}
%====================================
Since we have 6 group actions it's worth taking the time to see what kinds of expressions we obtain by applying $g$ on $Q_i^0$ or $K_i$ for each $i$. For example $g_i Q_i^0 = Q_i^0$ so we will say the action of $g_i$ is reduced to $g_{\emptyset} = 1$ on $Q_i^0$. Using the sequences $L$ produced in one orbit of a representation of $G$ and their alternatives we can tabulate their reductions on the different expresions. For example
\begin{align}
g_{2121}Q_1^0 = g_{212}Q_1^0 = g_{121} Q_1^0 = g_{12}Q_1^0
\end{align}
where on the second step we've used the alternative form $g_{212} = g_{121}$. The table has $12$  in the row and column corresponding to $2121$ and $Q_1^0$. We'll omit the row corresponding to the identity.
\begin{table}[H]
    \caption{Reductions of group actions $g \in G$ on $Q_i^0$ and $K_i$}
    \label{tbl:tableG6}
    \centering

    \toprule
    Sequence $L$ & Alternative & $Q_1^0$ & $Q_2^0$ & $K_1$ & $K_2$ \\ 
    \midrule

    2121 & 12 &  12 & 1 & 12 & 12 \\
    12121 & 2 &  2& $\emptyset$& 2& 2 \\
    \bottomrule
    \end{tabular}
\end{table}
We only have 6 different functions results of applying $G$ on $Q_1^0$ and $Q_2^0$ so we have only 6 variables that we may wish to eliminate.  Let
\begin{align}
	u_1 &= Q_1^0\,,\quad u_2 = g_2 Q_1^0\,,\quad u_3 = g_{12}Q_1^0\\
	v_1 &= Q_2^0\,,\quad v_2 = g_1 Q_2^0\,,\quad v_3 = g_{21}Q_2^0\,.
\end{align}
Also there are 12 different $K_1$'s and $K_2$'s which we label sequentially as $A_1,\ldots,A_6$ and $B_1,\ldots,B_6$ respectively. The associated matrix to the linear system of equations is
\begin{align}
	M_6 = \begin{bmatrix}
	A_1& & & B_1 & & \\
	A_2& & & & B_2& \\
	& A_3& & & & B_3\\
	& & A_4 & & & B_4\\
	& & A_5& & B_5& \\
	&A_6 & &B_6 & & \\
	\end{bmatrix}
\end{align}
and it has determinant
\begin{align}
	\det M_6 = A_2A_4A_6 B_1 B_3 B_5 - A_1 A_3 A_5 B_2 B_4 B_6\,.
\end{align}
The even index $A's$ are obtained by applying $g_1$ on the odd indx $A's$ and vice versa for the $B's$. That is,

	\det M_6 = \Delta_1 (A_2A_4A_6 B_1 B_3 B_5) = \Delta_1(g_1K_1 g_{121}K_1g_{12}K_1 K_2 g_{21}K_2 g_{12}K_2)\,.

We seek the same type of relation on $\beta$ and its orbit as for groups of order 4 so we'll use $D_G$ as inspiration for the sign changes. We have the following
\begin{align}\begin{split}
0=&\gamma\beta-\gamma_{1}\beta_{1}+\gamma_{21}\beta_{21}-\gamma_{121}\beta_{121}+\gamma_{12}\beta_{12}-\gamma_{2}\beta_{2}\\
	=&\gamma (A_1 u_1 + B_1 v_1) - \gamma_{2} (A_6 u_2 + B_6 v_1) - \gamma_{1} A_2 u_1 + B_2 v_2) \\&+  \gamma_{12} (A_5 u_3 + B_5 v_2) + \gamma_{21}(A_3 u_2 + B_3 v_3) - \gamma_{121} (A_4 u_3 + B_4 v_3)\,.
\end{split}\end{align}
Expanding out and collecting terms produces the system
\begin{align}
	 A_1 \gamma&= A_2 \gamma_{1}\,,\quad   \quad A_3 \gamma_{21} = A_6 \gamma_{2}\,,\quad \quad A_5 \gamma_{12} = A_4 \gamma_{121}\,,\\
	 B_1 \gamma &= B_6\gamma_{2}\,,\quad  \quad  B_5 \gamma_{12}= B_2 \gamma_{1}\,,\quad  \quad B_3 \gamma_{21} = B_4 \gamma_{121}\,.
\end{align}
This system of equations doesn't have a nontrivial symbolic solution so we need to use the relations here. There is a rational solution in each case with relations where $\gamma$ is a free variable. We set $\gamma$ to be the least common multiple of the denominators. We find that $K_0 = \gamma$ in each of the four cases with relations.

It's worth mentioning that it doesn't seem that all Coxeter groups are manifested in random walk models. Looking at the classification of finite Coxeter groups, those of rank 2 have orders 4, 6, 8, 12, 10 and 2$p$ (manifested in a $p$-gon). Namely the groups of orders 10,12 and 2$p$ (for most $p$) are not manifested in random walk models with small steps on the quarter plane. It appears that the $p$-gon symmetries are not present for most $p$ because of the crystallographic nature of the problem. It's quite possible that the Crystallographic restriction theorem will apply to the random walk model groups in all dimensions. However, as can be seen, a lot of random walk model groups in 2 dimensions have generators that don't map the lattice back onto itself in a simple way because the transformations are bi-rational. We can define classes of groups.

\begin{itemize}
\item a model is "nice" iff $g_i(x_i) \in \ze[x_1,\ol{x}_1\ldots,x_d,\ol{x}_d]$
\item a model is "crystallographic" iff $g_i(x_1^{n_1}\ldots x_d^{n_d}) = x_1^{m_1}\ldots x_d^{m_d}$ for some integers $n_j$ and $m_j$.
\end{itemize}
The names are suggestive because the generators in crystallographic random walk models map monomials to monomials and we can see if $G$ is crystallographic. The next step up are "nice" models where monomials are mapped to Laurent polynomials. The rest of the classes have a generator mapping some monomials to rational functions. Perhaps those first two types of models can be represented via reflections and will thus have Weyl group.

This discussion suggest a deeper theory of which we may just give the first few definitions
\begin{definition} For a model $\mc{M}$ of type $N$ with pure operator $\mc{E} = 1- E'$ so that $W = \fullx xdN  +\mc{E}W$ let
\begin{align}
	X_{d,\mc{M}} = \{\text{Operators $D$}| D\mc{E} \equiv 0 \text{ on generic functions with $\leq d -1$ variables missing}\}
\end{align}
\end{definition}
This space is not empty since $\fullx{\del} dN \in X_{\mc{M}}$ as shown already. Also we have the orbital operator for type $N$ models.
\begin{definition} For any type $N$ model in $d$ dimensions define
\begin{align}
	X_d  = \{\text{Operators $D$}| D\mc{E} \equiv 0 \text{ on generic functions with $\leq d -1$ variables missing}\}
\end{align}
where $\mc{E}$ is for any model $\mc{M}$.
\end{definition}
We can define similar spaces $X_{d,\mc{M}}(F)$ and $X_d(F)$ where we want the extra property $D(Ff) = FD(f)$ for any function $f$. We can further define spaces $X^\ast$ where in addition to having that nice property on $K$ we have that $D(\fullx xdN) \neq 0$. This will help characterize all problems which have a useful orbit summation for example. And in the case where such summation does not exist we may look towards other useful operators that let us perform an analysis on the D-finiteness of $Q$.
